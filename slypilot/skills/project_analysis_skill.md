# Project Analysis Skill

But :
comprendre un projet local à partir de sa structure, de sa cartographie et de son contexte borné.

Méthode :
- détecter le projet
- vérifier sa préparation
- lire la cartographie disponible
- interpréter les signaux techniques
- recommander la prochaine étape la plus utile

Sortie attendue :
- diagnostic interprété
- limites visibles
- prochaine étape recommandée
