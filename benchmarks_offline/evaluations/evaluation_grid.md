# Evaluation Grid

Score each criterion from `0` to `4`.

## Criteria

1. Respect du périmètre
2. Utilisation correcte du contexte
3. Absence d'hallucination structurelle
4. Précision technique
5. Réponse actionnable
6. Simplicité
7. Réduction d'entropie

## Scale

- `0` = mauvais
- `1` = faible
- `2` = acceptable
- `3` = bon
- `4` = excellent

## Maximum

`28` points total per response.

## Comparison rule

Evaluate the direct capture and the SlyPilot capture for the same prompt using the same grid.

Do not normalize away differences.
Do not infer missing facts.
Base the score only on the captured text.
