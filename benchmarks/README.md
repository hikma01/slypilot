# Benchmarks

This folder stores reproducible benchmark inputs and outputs for Phase 8.

Structure:

- `prompts/` official prompt texts
- `direct/` direct-provider captures
- `slypilot/` SlyPilot-assisted captures
- `evaluations/` manual comparison files

Rules:

- keep prompts fixed
- keep provider/model fixed during a batch
- persist failures as files
- do not score automatically
