# Evaluation Grid

Score each criterion from `0` to `4`.

## Criteria

1. Respect du périmètre
2. Utilisation correcte du contexte
3. Absence d'hallucination structurelle
4. Précision technique
5. Réponse actionnable
6. Simplicité
7. Réduction d'entropie

## Score interpretation

- `0` = mauvais
- `1` = faible
- `2` = acceptable
- `3` = bon
- `4` = excellent

## Maximum

`28` points
